About Us

Twenty-five free tools for images, text and everyday developer work — all running inside your browser.

Our mission is simple: build the small tools people need every day, keep them free, and make sure none of them asks you to hand over your files. Every tool here does one job, does it properly, and runs entirely inside your browser.

The toolbox started with image compression, because that is where the need is most obvious. Millions of images are uploaded to the internet every day and far too many of them are several times larger than they need to be — slowing websites down, burning mobile data and dragging search rankings lower. The answer was a set of tools that compress, resize, crop and convert an image in seconds, with no sign-up, no upload and no waiting.

The same reasoning applies to everything added since. Formatting a block of JSON, turning a timestamp into a date, checking what a colour looks like next to its complement, or counting the words in a draft: small jobs, but done by hand they cost minutes, and done carelessly they cost more. So the image tools now sit alongside text tools and developer tools, twenty-five in total, all built to the same rules.

Those rules are worth stating plainly. Your data stays on your device — every tool is JavaScript running on the page, and there is no server that receives anything, so there is nothing to log and nothing to leak. The tools are genuinely free, with no account, no usage limit and no paid tier. And they are honest about what they do: if PNG compression cannot shrink a file, the tool says so rather than pretending otherwise.

This is an independent project, built and maintained with care by a solo developer rather than a faceless company. That means feedback genuinely shapes what gets built next, so if a tool is missing something or does not behave as you expect, please get in touch.

Whether you are a developer shipping a faster website, a designer exporting assets, a writer checking a word count, or simply someone who needs a smaller file, these tools were built for you. Thank you for using them.
