    How to resize an image

    1. Upload a JPG, PNG or WebP image. WebP is selected as the output format by default because a resized photo stays smallest as WebP; switch to JPG or PNG under Output format if you need a specific file type.
    2. Pick a target size under Resize — fit within 1920, 1280 or 800 pixels, or scale to 50% or 25% of the original.
    3. Check the before-and-after preview. The output dimensions are shown next to the compressed size.
    4. Download the resized image.

    Why resize instead of just compressing?

    File size scales with the number of pixels. A photo straight from a phone or camera is usually 3000–4000 pixels wide, while the page or email you are putting it in will display it at 800–1600 pixels. Resizing removes the pixels nobody will ever see, and that shrinks the file far more than any quality setting can.

    Resizing is a one-way operation: detail that is thrown away cannot be recovered by scaling the image back up, so keep the original file if you might need it later. Everything here runs in your browser, so the images you open are never uploaded anywhere.

    Which target size should you choose?

    • Fit within 1920 px — full-width hero images and desktop banners.
    • Fit within 1280 px — in-article images and blog headers.
    • Fit within 800 px — thumbnails, cards, and anything only viewed on a phone.
    • 50% / 25% — keep the original proportions and just make a smaller copy.
