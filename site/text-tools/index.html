Free Online Text Tools

Four small text utilities that do the tedious parts of writing and editing — instantly, and without sending your text anywhere.

Most text chores take seconds to describe and minutes to do by hand. How long is this draft? How does this heading read in sentence case? Which of these two hundred lines are duplicates? The four tools below answer those questions without a download, an account or an upload — the text stays in the browser tab.

Word CounterLive word, character, sentence and paragraph counts, plus reading and speaking time estimates. Case ConverterSentence case, Title Case, UPPER CASE, camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE and URL slugs. Line Sorter and Duplicate RemoverSort A to Z or Z to A, remove duplicates and blank lines, trim whitespace, number or shuffle a list. Lorem Ipsum GeneratorPlaceholder paragraphs, sentences or words, plain or wrapped in HTML paragraph tags.

When each one earns its place

The word counter is the one people need most often, because so many places impose a limit — an essay, a meta description, a cover letter, a product title. It gives you the numbers a form will measure you by, along with the reading and speaking times that tell you whether a piece is the length it feels like. The character count is the one to trust when a limit is strict, since "a word" is not a fixed thing and different tools count it differently.

The case converter does two jobs that look unrelated but are really the same job. For prose, it switches a heading between title case and sentence case without you retyping it. For code, it converts a name between the conventions different languages use — a JSON property in snake_case arriving in a JavaScript project that wants camelCase, for instance — which is exactly the kind of edit that produces silent bugs when done by hand.

The line sorter exists for the moment a list stops being readable. Two blank lines at the end of a file, the same address entered twice with a stray space, item2 landing after item10 because a plain text sort put it there: none of those are hard problems, but all of them are tedious at scale, and each is one button here.

The Lorem Ipsum generator is a design tool rather than a writing one. Placeholder text exists so that a mockup can be judged on its layout instead of its wording. Generate paragraphs or an exact number of words, wrap them in p tags, and paste the result straight into a template.

Why nothing is uploaded

Every one of these tools is a small piece of JavaScript running on the page you are looking at. There is no server doing the work, which means there is no copy of your text anywhere else: a draft article, a list of customer names and a set of email addresses all stay on your own machine. That is not a marketing claim but a mechanical fact — the tab has no code that transmits anything, and closing the page removes the text with it.
