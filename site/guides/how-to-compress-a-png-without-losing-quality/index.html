How to compress a PNG without losing quality

PNG is a lossless format. That single fact explains why PNG files are so large, and why "compress this PNG" is a harder question than it looks. You cannot simply lower a quality slider the way you can with JPG — there is no quality slider, because no pixels are allowed to change.

So there are really two answers, and you need to know which one you want.

Answer 1: lossless PNG compression (zero pixel change)

This reduces the file without touching a single pixel. It works because a PNG is not stored as a grid of colours — it is stored as a compressed stream, and that stream is often bigger than it needs to be. Lossless tools shrink it by:

  • Re-compressing the stream more efficiently. Two tools can write the same pixels into PNG containers of very different sizes. Better compression settings alone can save 5–25%.
  • Stripping metadata. Editing software often embeds colour profiles, EXIF, and sometimes a full editing history. None of it changes the pixels, and all of it is dead weight in a file you are going to publish.
  • Reducing colour depth when the image allows it. A screenshot or a flat logo may use only 40 distinct colours. Storing it as a 256-colour palette image instead of 16.7 million colours is still lossless — as long as the palette covers every colour actually used.

All three are genuinely lossless. If you open the result and the before/after images are identical, the compression did its job correctly.

Answer 2: when lossless is not enough

Here is the honest limitation: if you have a 4 MB PNG that is a photograph, lossless compression will not save you. A photograph uses far more distinct colours than a logo, so there is little redundancy to exploit. Expect 10–20% and then a wall.

Past that wall you have three real options, and only these three:

  • Shrink the dimensions. A 4000px-wide photo displayed at 1200px is carrying roughly nine times more pixels than it needs. This is usually the biggest single win and it costs nothing visible.
  • Change the format. For photographs, WebP or JPG will be dramatically smaller. You give up losslessness, but for a photo on a web page nobody will see the difference at a sensible quality setting.
  • Accept the size. If the PNG must stay a PNG (transparency, exact colour, print, a design handoff), keep it and find the savings elsewhere on the page.

Which files should stay PNG?

PNG earns its place when you need one of these:

  • Transparency — logos, icons, product cut-outs on a transparent background.
  • Exact colour — flat UI graphics, charts, anything where a shifted shade looks like a bug.
  • Sharp edges and text — screenshots. JPG smears hard edges into fuzzy halos; PNG keeps them crisp.

If your image is none of those — it is a photo, a gradient-heavy render, or a big banner — PNG is probably the wrong container and reformatting will beat any compression setting.

Frequently asked questions

Does compressing a PNG reduce quality?

Not if the compression is lossless. Lossless PNG compression changes how the pixels are stored, not what they are. Quality only drops when you convert to a lossy format such as JPG or WebP.

Why is my PNG still large after compressing?

Because it is probably a photograph. Lossless compression finds little redundancy in photographic detail. Resizing the dimensions or converting to WebP/JPG is the fix.

Is WebP lossless for PNG content?

WebP has both a lossless and a lossy mode. Its lossless mode is generally smaller than PNG for the same pixels, but browser and tool support for lossless WebP is less universal than for PNG. For transparency on the web, PNG is still the safest default.

Can I compress a PNG on my phone?

Yes. Open this page in your mobile browser and pick a file from your gallery or files app. The compression happens on the device.
