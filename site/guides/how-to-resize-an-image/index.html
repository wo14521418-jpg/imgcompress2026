How to resize an image without ruining it

Resizing is the single most effective way to make an image smaller, and also the fastest way to destroy one. The difference between the two is knowing what you are actually changing.

What resizing really does

An image is a grid of pixels. Resizing rewrites that grid: a 4000-pixel-wide photo might become 1280 pixels wide, which means roughly nine out of every ten pixels are thrown away and the remaining ones are blended to fill the gaps.

That is why resizing is a one-way trip. You can scale an image back up, but the detail that was discarded is not recorded anywhere, so the enlarged version looks soft. Always keep the original file.

Pick the size from the destination, not from the camera

The mistake almost everyone makes is resizing to a "nice round number" instead of to the size the image will actually be displayed at. Work backwards instead:

  • Full-width banner or hero — 1920 pixels wide covers virtually every desktop layout.
  • In-article image or blog header — 1280 pixels wide.
  • Thumbnail, card or avatar — 400–800 pixels wide.
  • Email attachment — 1600 pixels on the long edge is generous; 1200 is fine for phone viewing.
  • Print — resize by the required dots per inch, not by eye. This is the one case where keeping a large file is correct.

If the image will be displayed at 1200 pixels wide, there is no benefit in shipping 3000 pixels — the visitor downloads and decodes pixels that the screen cannot show.

Keep the proportions

Changing width and height independently distorts the image: circles become ovals and faces get wider. Unless you deliberately want a different shape, scale both sides by the same factor. Every option in the image resizer on this site preserves the original proportions for you — the image is fitted inside your target size rather than stretched to it.

Do it in the right order

  1. Start from the original. Not a copy that has already been compressed, resized or screenshotted.
  2. Resize once to the largest size it will be displayed at.
  3. Then compress the smaller image. Because there are far fewer pixels to encode, even a mild quality setting gives a small file — and you keep more visible detail than if you had compressed first and shrunk afterwards.
  4. Check it at 100%. Look at an area of fine texture or a face. If it looks clean at full size, it will look clean in the layout.

Sharpening: usually a mistake

After downscaling, some editors offer to sharpen the result. A small amount can help a photograph taken with a soft lens, but applied to text, logos or screenshots it produces halos around the edges that look worse than the softness it was meant to fix. For screenshots and graphics, resize and stop there.

Frequently asked questions

Does resizing an image reduce its quality?

Making an image smaller discards detail, but if the new size matches how it will be displayed, nobody can see the difference. Making it larger almost always loses quality, because the extra pixels have to be invented.

How do I resize an image without stretching it?

Change the width and height by the same factor, or use a tool that fits the image inside a target box while preserving the aspect ratio. In the image resizer, choosing "Fit within 1280 px" keeps the proportions automatically.

What is a good size for a website image?

1280 pixels wide is a safe default for in-article images, 1920 for full-width banners, and 400–800 for thumbnails. There is rarely any reason to publish an image wider than 1920 pixels.

Can I resize an image on my phone?

Yes. Open the resizer in your mobile browser, pick a photo from your gallery, choose a target size and download the result. Nothing is uploaded.

Is resizing the same as compressing?

No. Compressing reduces the file size at the same dimensions; resizing changes the dimensions. See compression vs resizing for the full comparison.
