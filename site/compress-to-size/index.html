How the target size search works

Most compressors ask you to guess a quality number and then check the resulting file size yourself, adjusting and exporting again until it happens to fit. This tool flips that around: you give it the limit that matters — the one an upload form, a job portal or an email gateway enforces — and it finds the quality setting for you.

  1. It encodes the image at the highest quality and checks the size.
  2. If that already fits, it stops there and hands you the file.
  3. If it does not, it tests the lowest quality, then repeatedly halves the gap between the two to zero in on the best setting that still fits.
  4. If even the lowest quality overshoots, it scales the image down slightly and runs the same search again — a photo with fewer pixels needs fewer bytes at the same quality.

You get the sharpest file that stays inside your limit, along with the output dimensions and the quality setting that was used, so you can see exactly what happened.

Which target size should you pick?

  • 100 KB — a common ceiling for email attachments, forums and older upload forms.
  • 200 KB — a good all-round web image: sharp on a retina screen, light enough to load fast.
  • 500 KB — full-width hero images, online marketplaces and print-on-demand uploads.
  • 1 MB and above — when a gallery or marketplace wants a high-resolution original but still enforces a cap.
  • Under 100 KB — thumbnails, avatars and email signatures where the image is displayed small anyway.

If you do not know the limit, aim for the smallest file that still looks clean at the size it will be displayed. For a web page that is usually 100–200 KB; for a phone-only thumbnail it can be 30 KB.

Why resize as well as compress?

File size tracks the number of pixels. Quality settings shrink a file by storing the same pixels more economically; resizing removes pixels that nobody will see. When a target is very small — say 50 KB for a photo straight off a phone — resizing is the only honest way to get there, which is why the tool falls back to it automatically and shows you the new dimensions.

Frequently asked questions

How do I compress an image to exactly 200 KB?

Upload it, type 200 in the target size box (or click the 200 KB button) and wait a moment. The tool searches for the best quality setting whose output is 200 KB or less and downloads as soon as you click the button.

The result is under my target. Is that a problem?

No, it is intentional. The tool returns the largest file that still fits, so it usually lands just under your limit instead of overshooting it. Upload forms that reject a 201 KB file will accept a 199 KB one.

Can it compress a PNG to 100 KB?

Yes, but the output will be WebP or JPG, because PNG has no quality setting to lower. If the image has to stay a PNG, reduce its dimensions instead and keep the transparent areas small.

Is there a file size limit for uploading?

No hard limit, but very large images take longer because several encodings are tested. Anything up to about 50 MB is fine on a normal laptop.

Are my images uploaded to a server?

No. The whole search runs in your browser with the canvas API, so the file never leaves your device. You can confirm this by turning off your internet connection after the page has loaded.
