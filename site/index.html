    Why image compression matters

    Images make up a large share of the weight of most web pages. Oversized images slow down load times, consume mobile data, hurt your Core Web Vitals, and push your site down in search rankings. Compressing an image before you upload it is one of the fastest, cheapest ways to make a website faster — and it costs you nothing.

    How it works. Choose a compression level — Normal, Strong, or Extreme. If the image is bigger than it needs to be, set a target size under Resize as well: fit within 1920, 1280 or 800 pixels, or scale it to 50% or 25%. Pick an output format (WebP is recommended for the smallest files). Then drag in one image for a live before-and-after preview, or drop in several at once to batch-compress and download everything as a single ZIP archive. Everything runs locally in your browser, so your images never leave your device.

    Two more tools cover the cases the main box cannot. If a form or portal enforces an exact limit, Compress to Size searches for the best quality that still fits it, and reports the dimensions and quality it used. If the framing is wrong rather than the size, Crop Image cuts the picture to a free selection or a fixed ratio such as 1:1 or 16:9 before you compress.

    Format changes live under the Image Converter, which switches a file between JPG, PNG and WebP and lets you choose the colour that replaces transparency. There are dedicated pages for the conversions people need most — PNG to JPG, JPG to PNG and WebP to JPG, the last of which converts a whole batch at once. If you need several images inside a single document, Image to PDF builds one with A4, Letter or fit-to-image pages.

    Frequently asked questions

    Will this tool save my images?

    No. All image processing happens locally in your browser. We never upload, save or collect any of your image data.

    Which formats are supported?

    JPG, PNG and WebP are supported. Output defaults to WebP (smaller files) and can be switched to JPG or PNG.

    Does this tool resize images too?

    Yes. After uploading, use the Resize control to fit the image within 1920, 1280 or 800 pixels, or scale it to 50% or 25% of the original. The output dimensions are shown next to the file size, and there is a dedicated image resizer if that is all you need.

    Can I compress an image to an exact file size?

    Yes. The Compress to Size tool searches for the highest quality that still fits a limit you set — 100 KB, 200 KB, 500 KB or any other number — and shows the dimensions and quality it used. Use it whenever a form or portal enforces a maximum upload size.

    Is there a file size limit?

    In theory, no. However, very large images (over 50 MB) may process slowly depending on your device; we recommend processing them in batches.

    Is this tool free?

    Yes, the current version is completely free to use.
