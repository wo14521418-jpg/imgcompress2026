How to make a PDF from images

  1. Drop in the images you want in the document. JPG, PNG and WebP are all accepted, and you can add them in several goes.
  2. Put the pages in order with the arrow buttons. Page 1 is the first image in the list.
  3. Choose a page size: A4 or Letter for anything that will be printed or submitted, or Fit to image to keep each page exactly the size of the photo.
  4. Set a margin and a quality level, then press Create PDF and download it.

Which page size do you need?

  • A4 — the default almost everywhere outside North America, and what most online application portals expect.
  • US Letter — the equivalent for the United States and Canada; 8.5 x 11 inches.
  • Fit to image — the page becomes the size of the picture, so there is no white border and no scaling. Ideal for reading on a phone or tablet, and for archiving a set of screenshots.

Automatic orientation gives each page the orientation that suits its image: portrait pages for tall scans and receipts, landscape pages for wide screenshots. If your document has to follow a rule — for example, every page portrait — set it explicitly instead.

What this tool does to your images

Each image is re-encoded as a JPEG and embedded in the PDF, which is how virtually all PDF readers store photographs. Two consequences are worth knowing about:

  • Transparency becomes white. A PNG logo with a transparent background will sit on a white page, because the PDF image stream has no alpha channel here.
  • Very large photos are scaled down. Images wider than 2400 pixels are reduced before embedding, which keeps the PDF a sensible size — a 6000-pixel photo adds nothing to a document that will be displayed at screen or print resolution. Reduce the quality setting further if you need an even smaller file for an upload limit.

Typical uses

  • Photographing several pages of a signed document with a phone and submitting them as one PDF.
  • Collecting receipts or invoices into a single file for an expense claim.
  • Turning a set of screenshots into a shareable walkthrough.
  • Building a simple photo portfolio or a visual price list.
  • Attaching scanned ID or forms to an application that only accepts PDF.

Frequently asked questions

Is there a limit on how many images I can combine?

No fixed limit. Ten to fifty pages is comfortable in a browser; for a very large document, build it in two parts and join them with a PDF tool afterwards.

Can I put two or more images on a single page?

Not in this tool — it creates one page per image, which covers the common cases of documents, receipts, scans and portfolios.

Is the PDF searchable?

No. Every page is an image, so text inside it is not selectable. Nothing here performs OCR (optical character recognition).

Are my photos uploaded to a server?

No. The PDF is written by your browser from the files you selected. Nothing is transmitted, and the file is never stored online.

The PDF is too big to upload somewhere. What should I do?

Set the quality to 75, use A4 with small margins, and if that is still too large, resize the images to around 1600 pixels wide first — fewer pixels is the most effective way to shrink a PDF.
