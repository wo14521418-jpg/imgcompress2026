Case Converter

Change the capitalisation of any text instantly — from Title Case to camelCase, snake_case or a URL slug.

How to convert text case

  1. Paste or type your text. The result updates as you type.
  2. Pick a style from the dropdown, or press one of the buttons for the nine most common conversions.
  3. Copy the converted text, or download it as a text file.

Everything happens in the browser, so a list of names or a draft heading never leaves your machine.

Which case to use, and when

For prose the choice is between two conventions. Sentence case — capitalising only the first letter of each sentence — is how ordinary text is written, and most style guides for the web prefer it for headings too, because it reads the way people speak. Title case capitalises the first letter of every significant word and is still standard in book titles, US newspaper headlines and many marketing pages.

For code the conventions are stricter, and following the local one matters more than which looks best. JavaScript, Java, Swift and Kotlin use camelCase for variables and functions and PascalCase for types and classes. Python and Ruby use snake_case for the same things. C, Java and many other languages use CONSTANT_CASE for values that never change. Where a name has to cross from one convention to another — a JSON property arriving from an API into a JavaScript project — converting it in one step is faster and far less error-prone than retyping it.

The slug option is a different job again. A URL slug has to survive being pasted into a browser, an email client and a chat app, so it is lower case, uses hyphens rather than spaces, and drops every character that is not a letter or a digit. That keeps the address readable and avoids the long percent-encoded sequences you get from leaving punctuation and non-English characters in place.

Case converter FAQ

Title case or sentence case?

Sentence case capitalises the first letter of each sentence, the way ordinary prose works. Title case capitalises the first letter of every significant word, the convention for headlines and book titles.

Which case should a variable name use?

Follow the language. JavaScript, Java and Swift conventionally use camelCase for variables and PascalCase for classes; Python and Ruby use snake_case; C-style constants use CONSTANT_CASE.

What does the url-slug option do?

It turns a title into a URL-friendly slug: lower case, words joined by single hyphens, and anything that is not a letter, a digit or a hyphen removed.

Is my text uploaded?

No. The conversion happens in your browser as you type, and nothing is sent to a server.
